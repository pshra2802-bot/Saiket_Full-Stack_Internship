# Task 3 - React To-Do List

## Saiket Systems - Full Stack Development Internship

A responsive To-Do List application developed using React.js as part of Task 3 of the Full Stack Development Internship.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Display total number of tasks
- Empty task message
- Responsive design
- Add tasks using the Enter key

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
