# Task 5 - Database Integration with MySQL

## Saiket Systems - Full Stack Development Internship

A REST API integrated with a MySQL database using Node.js and Express.js as part of Task 5 of the Full Stack Development Internship.

## Features

- Create a new user
- Retrieve all users
- Retrieve a user by ID
- Update an existing user
- Delete a user
- Store user data in MySQL
- Retrieve data from MySQL
- REST API using Express.js
- API testing using Postman

## Technologies Used

- Node.js
- Express.js
- MySQL
- MySQL2
- JavaScript
- REST API
- XAMPP
- phpMyAdmin
- Postman
