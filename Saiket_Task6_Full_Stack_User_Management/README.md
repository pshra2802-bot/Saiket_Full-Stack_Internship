# Task 6 - Full Stack User Management System

## Saiket Systems - Full Stack Development Internship

A full-stack User Management System developed as part of Task 6 of the Saiket Systems Full Stack Development Internship.

The application allows users to add, view, update, and delete user profiles. The frontend communicates with a Node.js and Express.js REST API, which stores and retrieves user data from a MySQL database.

## Features

- Add a new user
- View all users
- Edit user details
- Delete users
- MySQL database integration
- REST API using Express.js
- Frontend and backend communication using JavaScript Fetch API
- Responsive user interface
- CRUD operations
- Confirmation before deleting a user

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js
- CORS
- REST API

### Database

- MySQL
- MySQL2
- XAMPP
